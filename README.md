# 痕迹 · Footprints

23 个旅行目的地的摄影与材料拼贴展览。线上地址：https://smart-moomoo.github.io/traces/

## 浏览

点击地图上的具体风景，直接进入该地点的逐帧小故事。悬停或键盘聚焦时，局部柔和提亮并显示英文地名。地图可拖动、缩放，点击“全景”恢复整体视图。

故事播放一次后停在结尾，可以重播、暂停；画框按钮切换完整的上下海报。左右按钮仍可浏览相邻地点。首页没有可操控人物，也没有旅行手册入口。系统设置减少动态效果时默认暂停，故事可以主动播放。

## 材料与动画

故事以原海报下半幅为参照，保留暖白纸面、浅色贝壳层理、几何碎片基础、不规则消隐边缘和留白。动态取自原场景的水、光、植物、船与倒影，不额外安排陌生人物表演。

首页地图使用六张独立的 1448×1086 图片，代替原先六格图集里约 591×444 的单帧。西雅图也使用独立整图，其余地点使用各自的三列两行六帧图集。定格生成的不同帧仍可能有轻微纹理与构图变化；这不是视频插帧。

当前视觉小故事属于演示创作，不表示真实发生过的个人经历。艺术地图不代表精确地理距离或旅行顺序。

## 未来的个人故事

films.js 中每个地点保留 memory、emotion、personalStory 空值。未来可依据用户本人提供的回忆与感受设计新的画面，不推断私人经历。界面不会显示待填写的空卡。

## 本地与发布

运行 `python3 -m http.server 4173` 后打开本地端口。无需依赖安装、构建或 API 密钥。

GitHub Pages 已启用 GitHub Actions。推送到 main 后，`.github/workflows/pages.yml` 自动上传静态站点并发布。

## 文件

- assets/posters/：原始完整海报。
- assets/material-films/：回到原海报风格的故事。
- assets/map-frames/：首页独立地图帧。
- films.js：地点素材、节奏与未来故事字段。
- app.js：导航与逐帧播放器，支持独立帧和图集。
- asset-provenance-seattle.json、asset-provenance-materials.json、asset-provenance-map.json：内置 imagegen 提示与素材检查记录。

素材重绘使用内置 imagegen。图集中每帧的实际分辨率仍低于独立帧，放大查看时有清晰度上限。
